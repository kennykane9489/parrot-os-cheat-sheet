# Practice labs

[Home](../README.md)

These exercises use loopback and your own temporary files. They require no target downloads or intentionally vulnerable Internet service.

| Lab | Goal | Prerequisites | Time |
|---|---|---|---|
| [Local HTTP](01-local-http.md) | Serve a file, inspect HTTP and identify one local port. | Bash, Python 3, curl; Nmap optional | 10–15 minutes |
| [Archive integrity](02-archive-integrity.md) | Create/extract an archive and compare file bytes. | Bash, GNU tar, sha256sum, cmp | 10 minutes |
| [Python isolation](03-python-isolation.md) | Create a venv and verify its interpreter without downloads. | Python 3 with venv support | 10 minutes |

Progress is optional: copy [the checklist](progress.md) and mark it after completing each exercise. Do not equate syntax checks or illustrative output with a completed lab.
